1. AUTHENTICATION APIs (/api/v1/auth)
--------------------------------------------------------------------------------

1.1 Send OTP API: POST /api/v1/auth/send-otp
1.2 Verify OTP API: POST /api/v1/auth/verify-otp
1.3 Resend OTP API: POST /api/v1/auth/resend-otp
1.4 Country Code List API: GET /api/v1/auth/country-codes
1.5 Terms of Service API: GET /api/v1/auth/terms-of-service
1.6 Privacy Policy API: GET /api/v1/auth/privacy-policy

--------------------------------------------------------------------------------
2. PROFILE & KYC APIs (/api/v1/getProfile & /api/v1/profile)
--------------------------------------------------------------------------------

2.1 getProfile API: GET /api/v1/getProfile (or GET /api/v1/profile)
2.2 Interest Selection API: POST /api/v1/profile/interest-selection
2.3 Profile Edit API: POST / PUT /api/v1/profile/edit
2.4 KYC Verification API: POST /api/v1/kyc/verify

--------------------------------------------------------------------------------
3. AADHAAR KYC APIs (/api/v1/aadhaar)
--------------------------------------------------------------------------------

3.1 Aadhaar KYC Submit & Send OTP API: POST /api/v1/aadhaar/kyc-submit
3.2 Verify Aadhaar OTP API: POST /api/v1/aadhaar/otp-verify
3.3 Upload Aadhaar Card Document API: POST /api/v1/aadhaar/upload

--------------------------------------------------------------------------------
4. PROFILE / LIVE APIs (/api/v1/profile-live)
--------------------------------------------------------------------------------

4.1 Who Viewed Your Live / Interest API: GET / POST /api/v1/profile-live/viewed-interest
4.2 Profile Photo Upload API: POST /api/v1/profile-live/photo-upload
4.3 Face Scan Recognition API: POST /api/v1/profile-live/face-scan

--------------------------------------------------------------------------------
5. ACTIVITIES & SEARCH APIs (/api/v1/activities)
--------------------------------------------------------------------------------

5.1 Planning Today List / Selection API: GET /api/v1/activities/planning-today
5.2 Search API: GET /api/v1/activities/search
5.3 Popular Activities List API: GET /api/v1/activities/popular-activities
5.4 Recommended Partner List API: GET /api/v1/activities/recommended-partners
5.5 Product Details API: GET /api/v1/activities/product-details/:id
