1. AUTHENTICATION APIs (/api/v1/auth)
--------------------------------------------------------------------------------

1.1 Send OTP API
- Endpoint: POST /api/v1/auth/send-otp
- Description: Send 4-digit OTP to specified phone number via SMSGATEWAYHUB DLT SMS.
- Request Body:
  {
    "country_code": "+91",
    "phone_number": "7250642635"
  }

1.2 Verify OTP API
- Endpoint: POST /api/v1/auth/verify-otp
- Request Body:
  {
    "country_code": "+91",
    "phone_number": "7250642635",
    "otp_code": "8675"
  }

1.3 Resend OTP API: POST /api/v1/auth/resend-otp
1.4 Country Code List API: GET /api/v1/auth/country-codes
1.5 Terms of Service API: GET /api/v1/auth/terms-of-service
1.6 Privacy Policy API: GET /api/v1/auth/privacy-policy

--------------------------------------------------------------------------------
2. PROFILE & KYC APIs (/api/v1/getProfile & /api/v1/profile)
--------------------------------------------------------------------------------

2.1 getProfile API
- Endpoint: GET /api/v1/getProfile (or GET /api/v1/profile)
- Headers: Authorization: Bearer <token>

2.2 Interest Selection API (POST)
- Endpoint: POST /api/v1/profile/interest-selection (or POST /api/v1/interest-selection)
- Headers: Authorization: Bearer <token>
- Request Body:
  {
    "interested_in_gender": "Female"   // Options: "Male", "Female", "Other", "Both"
  }

2.3 Profile Edit API: POST / PUT /api/v1/profile/edit
2.4 KYC Verification API: POST /api/v1/kyc/verify

--------------------------------------------------------------------------------
3. AADHAAR KYC APIs (/api/v1/aadhaar)
--------------------------------------------------------------------------------

3.1 Aadhaar KYC Submit & Send OTP API
- Endpoint: POST /api/v1/aadhaar/kyc-submit (also POST /api/v1/aadhaar/send-otp)
- Headers: Authorization: Bearer <token> (multipart/form-data)
- Description: Submit Aadhaar KYC details (Name, Nickname, Aadhaar Number, Age) and upload front & back document images to trigger OTP.
- Form Data / Body Params:
  - full_name: "Alex Sharma"
  - nick_name: "Alex"
  - aadhaar_number: "123456789012"
  - age: "25"
  - front_image: (file upload - Aadhaar Front side)
  - back_image: (file upload - Aadhaar Back side)
- Response (200 OK):
  {
    "success": true,
    "api_name": "aadhaarKycSubmit",
    "message": "Aadhaar details and documents uploaded. OTP sent to Aadhaar-linked mobile number.",
    "ref_id": "adh_ref_1789380000000",
    "expires_in_seconds": 300,
    "data": {
      "full_name": "Alex Sharma",
      "nick_name": "Alex",
      "aadhaar_number": "XXXXXXXX9012",
      "age": 25,
      "front_url": "http://localhost:5000/uploads/front_image-123.jpg",
      "back_url": "http://localhost:5000/uploads/back_image-123.jpg",
      "kyc_status": "PENDING_OTP_VERIFICATION"
    }
  }

3.2 Verify Aadhaar OTP API
- Endpoint: POST /api/v1/aadhaar/otp-verify
- Headers: Authorization: Bearer <token>
- Request Body:
  {
    "ref_id": "adh_ref_1789380000000",
    "otp": "4321"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "Aadhaar KYC verification completed successfully",
    "aadhaar_status": "VERIFIED",
    "is_kyc_completed": true
  }

3.3 Upload Aadhaar Card Document API: POST /api/v1/aadhaar/upload
