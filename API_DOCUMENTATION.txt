1. AUTHENTICATION APIs (/api/v1/auth)
--------------------------------------------------------------------------------

1.1 Send OTP API: POST /api/v1/auth/send-otp
1.2 Verify OTP API: POST /api/v1/auth/verify-otp
1.3 Resend OTP API: POST /api/v1/auth/resend-otp
1.4 Country Code List API: GET /api/v1/auth/country-codes
1.5 Terms of Service API: GET /api/v1/auth/terms-of-service
1.6 Privacy Policy API: GET /api/v1/auth/privacy-policy

1.7 Single Sign-On (SSO) Login API
- Endpoint: POST /api/v1/auth/sso (or /api/v1/auth/sso-login, /api/v1/auth/google-sso, /api/v1/auth/apple-sso)
- Description: Authenticate user using Google, Apple, or Social SSO credentials.
- Request Body (JSON):
  {
    "provider": "GOOGLE",
    "id_token": "google_oauth_token_xyz",
    "email": "user@gmail.com",
    "name": "Rohan Mehta",
    "profile_image": "https://lh3.googleusercontent.com/a/photo.jpg"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "GOOGLE SSO authentication successful",
    "provider": "GOOGLE",
    "token": "eyJhbGciOiJIUzI1NiIsIn...",
    "user": {
      "user_id": "usr_sso_1726724500",
      "name": "Rohan Mehta",
      "email": "user@gmail.com",

2.0 COMBINED PROFILE & KYC UPDATE POST API
- Endpoint: POST /api/v1/profile/combined-update (or POST /api/v1/profile/edit, POST /api/v1/profile/update-all)
- Headers: Authorization: Bearer <token>
- Description: Allows updating profile fields (name, email, gender, dob, bio, city), interest selection (interested_in_gender), AND submitting KYC document info in a single call.
- Request Body (JSON):
  {
    "name": "Alex Sharma",
    "email": "alex@example.com",
    "gender": "Male",
    "interested_in_gender": "Female",
    "city": "Mumbai",
    "bio": "Music & travel lover",
    "document_type": "AADHAAR",
    "document_number": "123456789012"
  }

2.4 Profile Edit API: POST / PUT /api/v1/profile/edit
2.5 KYC Verification API: POST /api/v1/kyc/verify
