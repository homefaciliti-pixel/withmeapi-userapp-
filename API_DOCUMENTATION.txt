1. AUTHENTICATION APIs (/api/v1/auth)
--------------------------------------------------------------------------------

1.1 Send OTP API
- Endpoint: POST /api/v1/auth/send-otp
- Description: Send 4-digit OTP to specified phone number via SMSGATEWAYHUB DLT SMS.
- Request Body:
  {
    "country_code": "+91",
    "phone_number": "7250642635"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "OTP sent successfully to your mobile number via SMS",
    "data": {
      "country_code": "+91",
      "phone_number": "7250642635",
      "full_phone_number": "+917250642635",
      "otp_id": "otp_123456",
      "expires_in_seconds": 600
    }
  }

1.2 Verify OTP API
- Endpoint: POST /api/v1/auth/verify-otp
- Description: Verify 4-digit OTP code and issue JWT token.
- Request Body:
  {
    "country_code": "+91",
    "phone_number": "7250642635",
    "otp_code": "8675"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "OTP verified successfully",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "user_id": "usr_998877",
      "country_code": "+91",
      "phone_number": "7250642635",
      "full_phone_number": "+917250642635",
      "is_profile_complete": false,
      "kyc_status": "NOT_STARTED"
    }
  }

1.3 Resend OTP API
- Endpoint: POST /api/v1/auth/resend-otp
- Description: Resend 4-digit OTP code to the phone number.
- Request Body:
  {
    "country_code": "+91",
    "phone_number": "7250642635"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "OTP resent successfully to your mobile number via SMS"
  }

1.4 Country Code List API
- Endpoint: GET /api/v1/auth/country-codes
- Description: Retrieve supported country codes with flag icons and calling codes.

1.5 Terms of Service API
- Endpoint: GET /api/v1/auth/terms-of-service

1.6 Privacy Policy API
- Endpoint: GET /api/v1/auth/privacy-policy

2. PROFILE & KYC APIs (/api/v1/getProfile & /api/v1/profile)
--------------------------------------------------------------------------------

2.1 getProfile API
- Endpoint: GET /api/v1/getProfile (or GET /api/v1/profile)
- Headers: Authorization: Bearer <token>
- Description: Retrieve logged-in user profile details including token status, gender interest preference, photo verification status, and KYC status.
- Response (200 OK):
  {
    "success": true,
    "api_name": "getProfile",
    "message": "User profile fetched successfully",
    "data": {
      "user_id": "usr_998877",
      "name": "Alex Sharma",
      "country_code": "+91",
      "phone_number": "7250642635",
      "full_phone_number": "+917250642635",
      "email": "alex.sharma@example.com",
      "gender": "Male",
      "interested_in_gender": "Female",
      "dob": "1998-05-15",
      "bio": "Enthusiastic explorer and tech lover",
      "city": "Mumbai",
      "profile_image": "http://localhost:5000/uploads/default_avatar.jpg",
      "is_logged_in": true,
      "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "is_photo_verified": true,
      "photo_verification_status": "VERIFIED",
      "is_kyc_completed": false,
      "kyc_status": "NOT_VERIFIED"
    }
  }

2.2 Profile Edit API
- Endpoint: POST / PUT /api/v1/profile/edit
- Headers: Authorization: Bearer <token>
- Description: Update user profile details in MySQL.

2.3 KYC Verification API
- Endpoint: POST /api/v1/kyc/verify
- Headers: Authorization: Bearer <token>
- Description: Submit KYC document details for identity verification.
