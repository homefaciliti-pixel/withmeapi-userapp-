1. AUTHENTICATION APIs (/api/v1/auth)
--------------------------------------------------------------------------------

1.1 Send OTP API
- Endpoint: POST /api/v1/auth/send-otp
- Description: Send OTP to specified phone number for login/signup.
- Request Body:
  {
    "country_code": "+91",
    "phone_number": "9876543210"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "OTP sent successfully",
    "data": {
      "phone_number": "+919876543210",
      "otp_id": "otp_123456",
      "expires_in_seconds": 300
    }
  }

1.2 Verify OTP API
- Endpoint: POST /api/v1/auth/verify-otp
- Description: Verify OTP and return JWT authentication token.
- Request Body:
  {
    "phone_number": "+919876543210",
    "otp_code": "123456"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "OTP verified successfully",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "user_id": "usr_998877",
      "phone_number": "+919876543210",
      "is_profile_complete": false
    }
  }

1.3 Resend OTP API
- Endpoint: POST /api/v1/auth/resend-otp
- Description: Resend OTP code to the phone number.
- Request Body:
  {
    "phone_number": "+919876543210"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "OTP resent successfully"
  }

1.4 Country Code List API
- Endpoint: GET /api/v1/auth/country-codes
- Description: Retrieve supported country codes with flag icons and calling codes.
- Response (200 OK):
  {
    "success": true,
    "data": [
      { "name": "India", "code": "IN", "dial_code": "+91" },
      { "name": "United States", "code": "US", "dial_code": "+1" },
      { "name": "United Arab Emirates", "code": "AE", "dial_code": "+971" }
    ]
  }

1.5 Terms of Service API
- Endpoint: GET /api/v1/auth/terms-of-service
- Description: Fetch Terms of Service document for authentication flow.
- Response (200 OK):
  {
    "success": true,
    "data": {
      "title": "Terms of Service",

3. AADHAAR APIs (/api/v1/aadhaar)
--------------------------------------------------------------------------------

3.1 Send Aadhaar OTP API
- Endpoint: POST /api/v1/aadhaar/send-otp
- Headers: Authorization: Bearer <token>
- Description: Initiate Aadhaar authentication by sending OTP to registered mobile number.
- Request Body:
  {
    "aadhaar_number": "123456789012"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "OTP sent to registered mobile number linked with Aadhaar",
    "ref_id": "adh_ref_992211"
  }

3.2 Verify Aadhaar OTP API
- Endpoint: POST /api/v1/aadhaar/otp-verify
- Headers: Authorization: Bearer <token>
- Description: Verify Aadhaar OTP and complete verification.
- Request Body:
  {
    "ref_id": "adh_ref_992211",
    "otp": "654321"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "Aadhaar verification completed successfully",
    "aadhaar_status": "VERIFIED",
    "details": {
      "name": "Alex Sharma",
      "masked_aadhaar": "XXXXXXXX9012",
      "address": "Mumbai, Maharashtra"
    }
  }

3.3 Upload Aadhaar Card Document API
- Endpoint: POST /api/v1/aadhaar/upload
- Headers: Authorization: Bearer <token> (multipart/form-data)
- Description: Upload front and back photos of Aadhaar card.
- Form Data:
  - front_image: (file)
  - back_image: (file)
- Response (200 OK):
  {
    "success": true,
    "message": "Aadhaar document images uploaded successfully",
    "front_url": "/uploads/aadhaar_front_123.jpg",
    "back_url": "/uploads/aadhaar_back_123.jpg"
