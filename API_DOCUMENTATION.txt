1. AUTHENTICATION APIs (/api/v1/auth)
--------------------------------------------------------------------------------

1.1 Send OTP API
- Endpoint: POST /api/v1/auth/send-otp
- Description: Send OTP to specified phone number via DLT SMS.
- Request Body:
  {
    "country_code": "+91",
    "phone_number": "9876543210"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "OTP sent successfully via DLT SMS",
    "data": {
      "phone_number": "+919876543210",
      "otp_id": "otp_123456",
      "dlt_sender_id": "HMFCLI",
      "dlt_template_id": "1207173589889308632",
      "expires_in_seconds": 600
    }
  }

1.2 Verify OTP API
- Endpoint: POST /api/v1/auth/verify-otp
- Description: Verify OTP code and issue JWT token.
- Request Body:
  {
    "phone_number": "+919876543210",
    "otp_code": "123456"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "OTP verified successfully",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "user_id": "usr_998877",
      "phone_number": "9876543210",
      "is_profile_complete": false,
      "kyc_status": "NOT_STARTED"
    }
  }

1.3 Resend OTP API
- Endpoint: POST /api/v1/auth/resend-otp
- Description: Resend OTP code to the phone number.
- Request Body:
  {
    "phone_number": "+919876543210"
  }
- Response (200 OK):
  {
    "success": true,
    "message": "OTP resent successfully via DLT SMS"
  }

1.4 Country Code List API
- Endpoint: GET /api/v1/auth/country-codes
- Description: Retrieve supported country codes with flag icons and calling codes.
- Response (200 OK):
  {
    "success": true,
    "data": [
      { "name": "India", "code": "IN", "dial_code": "+91", "flag": "🇮🇳" },
      { "name": "United States", "code": "US", "dial_code": "+1", "flag": "🇺🇸" }
    ]
  }

1.5 Terms of Service API
- Endpoint: GET /api/v1/auth/terms-of-service
- Description: Fetch Terms of Service document for authentication flow.
- Response (200 OK):

    "success": true,
    "data": {
      "title": "Terms of Service",

1.6 Privacy Policy API

2. PROFILE & KYC APIs (/api/v1/profile & /api/v1/kyc)
--------------------------------------------------------------------------------

2.1 Get Profile API
- Endpoint: GET /api/v1/profile
- Headers: Authorization: Bearer <token>
- Description: Retrieve logged-in user profile details.

2.2 Profile Edit API
- Endpoint: POST / PUT /api/v1/profile/edit
- Headers: Authorization: Bearer <token>
- Description: Update user profile details in MySQL.

2.3 KYC Verification API
- Endpoint: POST /api/v1/kyc/verify
- Headers: Authorization: Bearer <token>
- Description: Submit KYC document details for identity verification.
